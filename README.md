### 🚀 Sobre mí

Diseño, despliego y opero infraestructura en producción para empresas y organismos públicos. Me especializo en **pipelines de CI/CD**, **contenedores con Docker Swarm**, **virtualización con Proxmox** y **redes**, y tengo base de desarrollo full stack, así que entiendo de punta a punta lo que despliego.

- ⚙️ Armo pipelines que van de `git push` a producción: test → build → imagen → deploy.
- 🖥️ Monto servidores on-premise y VPS: Proxmox, Swarm, Traefik, registry privado, VPN.
- 🌐 Configuro redes con MikroTik y UniFi, y telefonía IP (Grandstream UCM).
- 📚 Ahora aprendiendo: **Ansible**, **AWS** y **Azure**.
